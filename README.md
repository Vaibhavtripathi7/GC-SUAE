# LunarSpecNet: Multimodal Spectral Unmixing for Chandrayaan-2 IIRS Data

Physics-informed multimodal deep learning for unsupervised lunar mineral
mapping from Chandrayaan-2 IIRS hyperspectral data fused with TMC-2
topography and Clementine geochemistry.

## Installation

```bash
git clone https://github.com/Vaibhavtripathi7/LunarSpecNet.git
cd LunarSpecNet
pip install -e ".[dev]"
```
